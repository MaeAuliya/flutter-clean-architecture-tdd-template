# Visual System

This file defines the visual system of the product.

Because this repository is a template, the values in this file should be updated based on the actual product design.

## To Be Defined

- Color palette
- Typography scale
- Spacing system
- Border radius
- Icon style
- Button style
- Card style
- Form field style
- Empty state style
- Loading state style
- Error state style

## AI Guidance

AI agents should not introduce inconsistent visual patterns.

When creating new UI components, follow the existing theme, shared widgets, and design rules documented here.
