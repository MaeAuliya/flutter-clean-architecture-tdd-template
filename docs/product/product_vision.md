# Product Vision

This template is a Flutter Clean Architecture and TDD starter project designed for scalable mobile app development.

The goal is to provide:

- A consistent feature-based project structure
- Clean separation between data, domain, and presentation layers
- Testable business logic
- Modular dependency injection
- AI-ready documentation for coding agents
- Local file generation tools for features and modules
