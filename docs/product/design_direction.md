# Design Direction

This file defines the general design direction for the application.

Because this repository is a template, the final design direction should be filled after the product concept is clear.

## To Be Defined Per Product

- General design style
- User experience principles
- Navigation behavior
- Content hierarchy
- Screen density
- Interaction style
- Accessibility direction

## AI Guidance

Before implementing UI-facing work, AI agents should check this file and align UI decisions with the intended design direction.

If the design direction is not defined yet, AI agents should avoid making strong visual assumptions and should use neutral, reusable UI patterns.
