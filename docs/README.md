# Project Documentation

This folder contains project guidance for developers and AI coding agents.

## Documentation Structure

- `product/` contains product-facing guidance such as product vision, design direction, visual system, information architecture, and user flows.
- `patterns/` contains implementation rules for architecture, dependency injection, routing, provider registration, file generation, and testing.
- `TODO/` contains future improvements and roadmap notes.

## How AI Agents Should Use This Folder

Before making code changes, AI agents must read:

1. `AGENTS.md`
2. Relevant files under `docs/product/`
3. Relevant files under `docs/patterns/`
4. `docs/TODO/next_steps.md` when proposing future work

The `docs/patterns/` folder is the main source of truth for implementation consistency.
